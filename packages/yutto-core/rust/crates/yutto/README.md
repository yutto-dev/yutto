# yutto

This crate contains yutto's Rust download backend and its current PyO3 binding.
It integrates the generic `haya` downloader with the `haya-http` transport and
projects transfers into the API consumed by the Python yutto package.

The crate is under active migration. Its Rust API and Python binding surface may
change between `0.0.x` releases.
